# BasedCode design

The dark theme pairs the approved solid #1F241F wallpaper with subtly plum-tinted
working surfaces. The wallpaper colour was sampled from the supplied scene image;
the user explicitly preferred that visible reference over the source HTML value.

| Role | Colour |
|---|---|
| Wallpaper | #1F241F |
| Working surface | #19181B |
| Sidebar | #151417 |
| Deep surface | #111013 |
| Panel | #201E23 |
| Primary text | #FFFFFF |
| Muted text | #C1A7CE |
| Focus | #D7A4E2 |
| Selection | White on #472458 |

Semantic colours distinguish syntax, diagnostics and diffs while retaining readable
contrast. The exact-match wallpaper is a solid PNG without dithering or gradients.
The earlier near-grey animation remains an optional alternative, ordered after the
still so fresh installs select the approved exact colour.

Native Omarchy templates generate supported terminal and application integrations.
Targeted shell sections and the colour-only VS Code override preserve layout and
syntax mappings. Generic GTK applications use native dark mode with Yaru-purple icons.
No stock files, user fonts, monitor settings, shortcuts or layout preferences are changed.

The preview shows live Neovim, btop, a terminal listing and GNOME Files, with the same
sample content and geometry as the light sibling. The source artwork and colour
adaptations are original implementation work; brand rights remain separate.
